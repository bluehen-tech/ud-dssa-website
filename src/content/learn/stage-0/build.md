## Before Stage 1

You need:

- A laptop running Windows or Mac. A Chromebook or tablet will not work for the build steps.
- Permission to install apps on that laptop.
- About one hour for each stage. You can stop between stages and pick up later from the path map.

Sign-in on this site lasts four hours. If you come back later, sign in again and open the path map. Your progress is saved.

Every build card ends with a **Done when** list. Tick each item before you move on.

## Done when

- [ ] You have a Windows or Mac laptop you can install apps on
- [ ] You know where the path map is: bluehen-dssa.org/learn
