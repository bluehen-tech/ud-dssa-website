# You are already on the site

Your portfolio is on bluehen-dssa.org. Six tools worked together to put it there. This path teaches each one, in order.

## What happened when you published

1. **You signed in.** Supabase checked your @udel.edu address and sent you a sign-in code. Resend delivered that email.
2. **You filled in a form.** The form is a page built with Next.js and styled with Tailwind CSS.
3. **You added a photo.** It was saved in Supabase Storage, which keeps files.
4. **You clicked Publish.** Your details were saved as one row in a database table called `member_portfolios`.
5. **The members page showed your card.** It read your row from the table. The site runs on Vercel, which puts it on the web.
6. **The code is on GitHub.** Every page and rule above is a file in the site's GitHub repository. Officers and members change it in Cursor, an editor with an AI agent built in.

The boxes above show these six tools. Each stage highlights the one it teaches.

## How each stage works

Each stage has three parts:

- A short lesson with one idea.
- A concept check of 3 to 5 questions. You need every answer right to pass. You can retake it as many times as you like.
- A build card. It unlocks when you pass. It lists the steps to do in Cursor and how you know you are done.

This path is not for credit. Your member card shows how many stages you have cleared, such as "Builder Path 3 of 7".
