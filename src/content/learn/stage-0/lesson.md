# You are already on the site

Your portfolio is on bluehen-dssa.org. This path shows you how the site works. Then you build a small site of your own, one piece at a time.

You do not need any coding experience.

## What happened when you published

1. **You signed in.** The site emailed a code to your @udel.edu address. Typing the code proved the address is yours.
2. **You filled in a form.** The form is one page of the site.
3. **You added a photo.** The site saved the photo file.
4. **You clicked Publish.** The site saved your details in its **database**. A database is where a site keeps its data, so the data is still there the next time you visit.
5. **The members page showed your card.** The page read your details from the database and drew your card.

Each step ran because someone wrote **code** for it. Code is text files that tell a computer what to do. DSSA members wrote the code for this site, and anyone can read it.

## Six jobs

The boxes at the top of this page show six jobs that keep the site running: write the code, keep the code, build the pages, put the site on the web, keep the data, and send email.

A different tool does each job. You do not need to know the tools yet. Each stage teaches one, and its box is highlighted.

:::more The names of the six tools
You will meet each tool when its stage comes. There is nothing to memorize now.

## How each stage works

Each stage has three parts:

- A short lesson. It opens with the short version, a few lines that state the ideas. If you know them already, go straight to the check.
- A concept check of 3 to 5 questions. You need every answer right to pass. You can retake it as many times as you like.
- A build card. It unlocks when you pass. It lists the steps to do on your laptop and how you know you are done.

Two things help as you read:

- A word with a dotted underline shows a plain definition when you tap it. Try this one: [[database]].
- A grey box marked Optional holds extra detail. Open it when you want more. The concept check never asks about it.
